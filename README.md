# moist — The Word You'd Delete From the Dictionary

One word, erased forever: **moist**.

Ask any English speaker which word makes them squirm and the same answer
comes back every time. It's not a slur, not a typo, not even a bad word —
it's just... *moist*. The sound alone makes people wince. It creeps into
cake reviews, weather reports, and basement descriptions where nobody asked
for it. Delete it from the dictionary and the language loses nothing: cakes
can be tender, air can be humid, basements can be damp. But the world gains
one less word that makes an entire room groan.

The humour is in the word itself — say it out loud and you'll feel why it
has to go.

## Run it

```bash
python3 main.py
```

Writes the word (plus a trailing newline) to `/output/entry.txt`. Pass an
optional path argument to write elsewhere, e.g. `python3 main.py entry.txt`.
